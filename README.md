# Student Offers Repository

A practical, source-linked catalog of free software, premium student plans,
credits, and trials for students.

> Last web review: **2026-08-21 (UTC)**. Offers can change without notice. The
> provider's current official page always wins.

Current snapshot: **60 direct free/education listings**, **83 GitHub Student
Developer Pack entries**, and **66 trial/credit rows**. Some rows intentionally
overlap so students can browse either by provider or by expiry risk.

## What is included

- Direct student plans that cost nothing while eligibility remains active.
- Limited free periods such as 1 month, 3 months, 6 months, or 1 year.
- One-time and recurring credits for AI, cloud, hosting, and developer tools.
- Institution-sponsored access when individual activation is unavailable.
- Region and school-level limitations stated by official sources.
- Billing and renewal warnings for offers that require a payment method.

## What is not included

- Coupon-code blogs without a matching provider or authoritative program page.
- Pirated licenses, shared accounts, account resale, or verification bypasses.
- Broad consumer free tiers with no education or professional-learning value.
  A small set of useful no-cost professional tools is included but clearly
  labeled when it is not student-exclusive.
- Expired offers presented as active.
- Affiliate or referral links.

## Status legend

| Label | Meaning |
|---|---|
| **Free while eligible** | No fixed end date, but re-verification may be required |
| **Free period** | Premium access ends after a stated duration |
| **Credit** | A monetary or usage balance; expiry and overage rules matter |
| **Institution-gated** | Your school must purchase, sponsor, or participate |
| **Discount after trial** | Starts free, then changes to a paid student price |
| **Check region** | Availability depends on country, university, or rollout |

## Contributing and maintenance

Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing an offer. Every active
listing needs an authoritative source, checked date, eligibility summary,
region, verification method, duration, and renewal note. The canonical fields
are documented in [the offer schema](docs/OFFER-SCHEMA.md).

The supplied GitHub workflows lint Markdown on changes and check external links
weekly. A human must still review offer terms because a working link does not
prove that a promotion remains active.

## Important notice

This is an independent community catalog, not an offer provider or student
verification service. Review [billing safety](guides/BILLING-SAFETY.md) and the
full [disclaimer](DISCLAIMER.md) before activating an offer.

## Completeness

The web does not have a finite, permanent list of student promotions. This is a
broad verified snapshot, not a promise that every offer in every country has
been found. Corrections with official evidence are welcome.
