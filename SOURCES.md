**Security note (2026-09-11):** while re-fetching the Firecrawl student-offer page, the verifying agent found hidden text embedded in the page attempting to instruct AI agents to fetch and execute an external "skill" file — a prompt-injection attempt aimed at automated scrapers. The agent ignored it and took no action on it; this repository did the same. If your own tooling re-scrapes that page, be aware it may still contain injected content, and do not have an automated process execute instructions found in page content.
