# GitHub Student Developer Pack — Benefit Index

Source: [GitHub Student Developer Pack](https://education.github.com/pack), reviewed 2026-08-21 and rechecked 2026-09-11. GitHub is the authoritative activation route. Partner benefits may change, disappear, or gain extra conditions without notice.

**2026-09-11 update:** GitHub's own docs now frame the Pack primarily as Copilot (including premium features) plus partner tools free for verified students. GitHub Pro is no longer listed as an included Pack benefit — many former Pro features became free for everyone on GitHub, so it stopped being a distinguishing Pack perk. The row below reflects that.

## Eligibility

- Students must be at least 13 years old.
- GitHub verifies current student status.
- Teachers, researchers, faculty, and staff use other GitHub Education programs and are not eligible for the student pack itself.
- Do not create duplicate accounts or misrepresent enrollment.

## Entries that need extra care

- A “free domain” can renew at the normal annual price. Disable auto-renew if you do not want that.
- Cloud credits do not automatically stop running infrastructure in every service.
- Free education licenses may forbid commercial or client work.
- GitHub's partner page may be newer than this file; compare the live text before claiming.
- Some benefits are ordinary free/open-source products included as learning resources, not premium student upgrades.
- The certification voucher is inventory-limited; being verified does not guarantee that vouchers remain available.
